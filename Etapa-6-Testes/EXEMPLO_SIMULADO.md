# Exemplo fictício de preenchimento da ficha de avaliação

> **Simulação didática.** Os cinco perfis e os resultados abaixo são inventados apenas para ilustrar como registrar o teste. **Não representam pessoas entrevistadas nem testes realmente realizados. Não utilizar como evidência de validação.**

## Perfis fictícios
| Código | Perfil hipotético | Familiaridade com internet |
|---|---|---|
| S01 | Adulto de 31 anos, utiliza celular no trabalho | Intermediária |
| S02 | Adulto de 62 anos, acessa mensagens e vídeos | Básica |
| S03 | Adulto de 45 anos, utiliza serviços bancários | Intermediária |
| S04 | Adulto de 24 anos, começou a usar computador | Básica |
| S05 | Adulto de 57 anos, utiliza poucos aplicativos | Básica |

## Resultados inventados para demonstrar o cálculo
C = concluiu, D = dificuldade, N = não concluiu.

| Perfil | T1 | T2 | T3 | T4 | T5 | Exemplo de comentário |
|---|---|---|---|---|---|---|
| S01 | C | C | C | C | C | “Navegação simples.” |
| S02 | C | D | C | C | D | “Não percebi o botão de aumentar texto.” |
| S03 | C | C | C | C | C | “O retorno poderia ficar mais visível.” |
| S04 | C | C | C | D | C | “O exemplo do quiz poderia ser maior.” |
| S05 | D | C | C | C | D | “Gostaria de mais figuras.” |

**Exemplo matemático, não resultado real:** 20 tarefas marcadas C em 25 tentativas = 80% de conclusão. Essa taxa foi obtida por dados fabricados e **não permite conclusões sobre usabilidade**.

## Três melhorias hipotéticas para avaliar
1. Deixar o botão de ampliar texto junto do conteúdo.
2. Dividir orientações em trechos ainda menores.
3. Destacar a opção de voltar ao início em todas as telas.

## Como substituir pela avaliação real
Aplicar as cinco tarefas descritas em [README.md](README.md) com cinco adultos voluntários, usar identificadores P01–P05, registrar observações reais sem dados pessoais, calcular a taxa observada e então registrar alterações efetivamente feitas no protótipo.
